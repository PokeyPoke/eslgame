# ESL Game - Printable Worksheets

Interactive printable worksheets designed for 2nd grade ESL learners, focusing on speaking practice and vocabulary building.

## 📚 Worksheets Included

### 2D Shapes (`2D_Shapes_Printable.html`)
- 8 complete student sets
- 10 shapes per set: Circle, Square, Triangle, Rectangle, Pentagon, Hexagon, Octagon, Diamond, Trapezoid, Parallelogram
- Format optimized for landscape printing
- Perfect for cutting and pasting into notebooks

### 3D Shapes (`3D_Shapes_Printable.html`)
- 8 complete student sets
- 10 shapes per set: Sphere, Cylinder, Cone, Cube, Rectangular Prism, Hexagonal Prism, Pyramid, Tetrahedron, Triangular Prism, Pentagonal Pyramid
- Same compact format as 2D shapes
- Landscape printing recommended

### Math Problem Sets (`Math_Problem_Sets.html`)
- 32 problem sets organized by word
- Each set has 3 chaining math problems
- Problem 1 answer goes into Problem 2
- Problem 2 answer goes into Problem 3
- Final answers (1-26) reveal letters using the included code
- **Secret Message:** KIDS LOVE MATH GAME WEEKEND PARTY TIME
- Problem formats include parentheses for order of operations practice

## 🖨️ How to Print

1. Open any worksheet in your web browser
2. Press Ctrl+P (Windows) or Cmd+P (Mac)
3. Select "Landscape" orientation for best results
4. Adjust margins as needed (narrow margins fit more content)
5. Print to PDF or directly to printer

- Encourage students to cut out shapes and create patterns
